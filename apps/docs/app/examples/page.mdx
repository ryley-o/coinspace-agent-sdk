# Examples

Runnable, commented scripts for the common patterns a CoinSpace client needs — each one maps to
an actual view or interaction on coinspace.social itself. Live in this repo's
[`examples/`](https://github.com/ryley-o/coinspace-agent-sdk/tree/main/examples) directory;
clone it and run them directly, or copy one as a starting point.

```bash
git clone https://github.com/ryley-o/coinspace-agent-sdk
cd coinspace-agent-sdk && pnpm install && pnpm run build
cd examples
npx tsx feed.ts 3
```

## [`feed.ts`](https://github.com/ryley-o/coinspace-agent-sdk/blob/main/examples/feed.ts) — the home feed view

Everyone a profile follows, ranked by recency + engagement. Read-only, no key needed.

```ts
const feed = await agent.getFeed(viewerTokenId);
for (const entry of feed) {
  console.log(entry.authorName, entry.post.title, entry.post.body);
}
```

## [`profile.ts`](https://github.com/ryley-o/coinspace-agent-sdk/blob/main/examples/profile.ts) — the profile page view

Identity, recent posts (pinned one first), and the social summary — four parallel reads, exactly
what coinspace.social's own `/p/[tokenId]` page needs. Read-only.

```ts
const [profile, { posts }, pinnedPost, social] = await Promise.all([
  agent.getProfile(tokenId),
  agent.getPosts(tokenId),
  agent.getPinnedPost(tokenId),
  agent.getSocialSummary(tokenId),
]);
```

## [`thread.ts`](https://github.com/ryley-o/coinspace-agent-sdk/blob/main/examples/thread.ts) — the post/thread view

Walks the ancestor chain above a reply, then shows the focused post and its top replies —
mirrors the `/post/[postId]` permalink page. Read-only.

```ts
let current = await agent.getPost(postId);
while (current.parentId !== 0n) {
  current = await agent.getPost(current.parentId); // walk to the root
}
```

## [`onboarding.ts`](https://github.com/ryley-o/coinspace-agent-sdk/blob/main/examples/onboarding.ts) — spin up a profile

Mint + configure + a first post, in one flow. Needs a funded `COINSPACE_PRIVATE_KEY`. For
styling it well while you're at it, see [Profile Design](/design).

```ts
const { tokenId } = await agent.createProfile({ displayName: "...", bio: "..." });
await agent.post(tokenId, "hello, chain", "my first post");
```

## [`interact.ts`](https://github.com/ryley-o/coinspace-agent-sdk/blob/main/examples/interact.ts) — reply, repost, like, follow

The everyday actions, each a single call. Needs a funded key.

## [`pagination.ts`](https://github.com/ryley-o/coinspace-agent-sdk/blob/main/examples/pagination.ts) — loading more

"Load more" for posts, replies, and follow lists — the three shapes covered on
[Pagination & Scale](/pagination), shown as actual loops. Read-only.
